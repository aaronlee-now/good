# Fun Games

A little browser-games site for **fungames.py.fun**.

## Files

- `index.html` — the landing page (links to the games)
- `style.css` — landing-page styling
- `snake.html` — Zoo Snake game page
- `snake.js` — Zoo Snake game logic + canvas visuals
- `snake.css` — Zoo Snake styling

## Games

- **Zoo Snake 🐍** — classic Snake set in a zoo. Eat fruit to grow while a
  zookeeper chases you. Arrow keys or WASD to move; don't hit the fences,
  yourself, or get caught.

## Preview locally

Open `index.html` directly in your browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
